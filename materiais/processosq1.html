Questões sobre Modelos de Processo de Software

Modelos de Processo de Software — Questionário

1) Em qual modelo o desenvolvimento é realizado em fases sequenciais e rígidas?
A) Iterativo
B) Incremental
C) Prototipação
D) Cascata
E) RAD
2) Qual modelo permite a entrega de partes funcionais do sistema durante o desenvolvimento?
A) Cascata
B) Incremental
C) Espiral
D) Modelo V
E) Evolutivo
3) Uma característica marcante do modelo iterativo é:
A) Ciclo fixo sem revisões
B) Entrega única apenas no final
C) Repetição de etapas com aperfeiçoamento progressivo
D) Ausência de feedback
E) Desenvolvimento simultâneo de todas as fases
4) O modelo incremental pode ser melhor representado por:
A) Construção de um edifício inteiro antes do uso
B) Liberação funcionalidade por funcionalidade
C) Implantação total no início
D) Aplicações isoladas por time
E) Ajuste apenas após a entrega
5) Assinale a alternativa INCORRETA sobre o modelo cascata:
A) Aborda de forma sequencial as fases de projeto
B) Possibilita revisitar fases anteriores com facilidade
C) Indicado para requisitos bem definidos
D) Pode dificultar mudanças
E) Cada etapa depende da anterior
6) O modelo incremental é especialmente indicado quando:
A) Todos os requisitos já são conhecidos e estáveis
B) O cliente deseja entregar valor rapidamente
C) Não há necessidade de feedback
D) Há apenas uma iteração de desenvolvimento
E) O projeto não permite entregas fragmentadas
7) O modelo iterativo é adequado para:
A) Contextos em que mudanças são indesejadas
B) Casos de melhoria e refinamento contínuos
C) Desenvolvimento por departamentos estanques
D) Projetos de ciclo único
E) Produtos normalmente imutáveis
8) No modelo cascata, alterações nos requisitos costumam:
A) Ser facilmente adaptadas em qualquer fase
B) Não impactar no desenvolvimento
C) Exigir reinício de etapas e causar retrabalho
D) Ser a regra mundial
E) Melhorar muito a qualidade sem custo
9) O que acontece ao final de uma iteração no modelo iterativo?
A) O projeto é descartado
B) O ciclo termina e não há aprendizados
C) Uma versão do sistema é avaliada e ajustada
D) Parte é esquecida
E) É feita uma manutenção corretiva somente
10) No modelo incremental, as funcionalidades:
A) São todas entregues de uma vez
B) Não podem ser testadas separadamente
C) São agregadas a cada ciclo, podendo ser usadas antes do fim do projeto
D) Permanecem invisíveis ao usuário até o final
E) Nunca sofrem alterações
